================================================================================
                DRONE HUNTER 2D - ANDROID MOBILE SETUP GUIDE
================================================================================

You can run Drone Hunter 2D on any Android phone using 2 different methods:

--------------------------------------------------------------------------------
METHOD 1: PYDROID 3 (EASIEST & RECOMMENDED - 100% FREE & INSTANT)
--------------------------------------------------------------------------------
No compilation required! Your Android phone will run the Python code natively:

  1. Open Google Play Store (or APKPure) on your Android Phone.
  2. Search and Install "Pydroid 3 - IDE for Python 3".
  3. Open Pydroid 3 -> Tap Menu (≡) -> Select "Pip" -> Type:
        pygame-ce
     and tap INSTALL.
  4. Copy the `drone_hunter` project folder to your Android phone's Internal Storage.
  5. In Pydroid 3, open `main.py` and tap the yellow Play (▶) button!

  * TOUCHSCREEN CONTROLS ON ANDROID:
    - Tap on screen = Flies drone towards touch & shoots cannon.
    - Tap UI Buttons = Activates difficulty modes, pause menu, and hangar upgrades.

--------------------------------------------------------------------------------
METHOD 2: BUILD A NATIVE ANDROID APK FILE (USING BUILDOZER)
--------------------------------------------------------------------------------
To compile a standalone `.apk` installer file that can be installed on any Android:

  1. Prerequisites: Linux or WSL (Windows Subsystem for Linux / Ubuntu).
  2. Install Buildozer:
        pip install buildozer
        sudo apt install -y git zip unzip openjdk-17-jdk python3-pip autoconf libtool pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev libssl-dev libffi-dev libsqlite3-dev build-essential
  3. In the project directory (`drone_hunter`), run:
        buildozer android debug
  4. Buildozer will compile `bin/DroneHunter-1.0.0-arm64-v8a-debug.apk`.
  5. Copy the `.apk` file to your Android phone and tap to Install!
