========================================================================
                      DRONE HUNTER - SCI-FI ARCADE GUIDE
========================================================================

1. HOW TO LAUNCH THE GAME
------------------------------------------------------------------------
Option A: Standalone Windows .exe (No Python Required)
  - Double-click:
      D:\AI_Projects\drone_hunter\dist\DroneHunterSingle.exe

Option B: Run from Python Source
  - Open Command Prompt or PowerShell and run:
      cd /d D:\AI_Projects\drone_hunter
      python main.py

------------------------------------------------------------------------
2. CONTROLS
------------------------------------------------------------------------
  [ Up Arrow / W / Spacebar ] - Fly / Thrust Upward
  [ Down Arrow / S ]         - Move Downward / Desend
  [ Left / Right Arrow ]     - Move Left / Right (A / D)
  [ Mouse Cursor ]           - Aim Tactical Cannons (360 degrees)
  [ Left Mouse Click ]       - Fire Energy Laser (Hold for continuous fire)
  [ Space / Enter / S ]      - Advance Level on Celebration Screen
  [ R / Space / S ]          - Restart Game after Game Over
  [ ESC ]                    - Exit / Quit Game

------------------------------------------------------------------------
3. GAMEPLAY & WEAPON UPGRADES
------------------------------------------------------------------------
- WEAPON TIERS PER LEVEL:
    * Level 1  : Single Laser Cannon
    * Level 2  : Double Twin Laser Cannons
    * Level 3+ : TRIPLE SPREAD LASER CANNONS (3 Beams Simultaneously!)

- BATTERY RECHARGE POWER-UPS:
    * Drone starts with 100% Battery Health.
    * Touch floating Green Battery Orbs to RECHARGE +30% Battery!
    * Battery Orbs spawn every 7s and drop from destroyed targets (35% chance).

- ENEMY TARGET TYPES:
    * Standard Target (Red Ring)    : Normal Speed, 1 HP, +10 pts
    * Fast Target (Magenta/Cyan)    : High Speed, Small, 1 HP, +25 pts
    * Armored Target (Crimson/Gold) : Heavy Shield, 3 to 5 HP, +50 pts

------------------------------------------------------------------------
4. HOW TO REBUILD THE STANDALONE .EXE
------------------------------------------------------------------------
Double-click `build_exe.bat` or run in Command Prompt:
    python -m PyInstaller --noconfirm --onefile --windowed --name "DroneHunterSingle" main.py
