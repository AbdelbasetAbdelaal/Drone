========================================================================
                      DRONE HUNTER - SCI-FI ARCADE GUIDE
========================================================================

1. HOW TO LAUNCH THE GAME
------------------------------------------------------------------------
Open Command Prompt (cmd) or PowerShell and run:

    cd /d D:\AI_Projects\drone_hunter
    python main.py

------------------------------------------------------------------------
2. CONTROLS
------------------------------------------------------------------------
  [ Spacebar ]        - Start Game / Upward Thrusters / Restart
  [ A ] / [ D ]       - Move Left / Right
  [ Left Arrow ]      - Move Left
  [ Right Arrow ]     - Move Right
  [ Mouse Cursor ]    - Aim Cannon in 360 degrees
  [ Left Mouse Click ]- Fire Energy Laser (Hold for continuous fire)
  [ R ]               - Restart Game after Game Over
  [ ESC ]             - Exit / Quit Game

------------------------------------------------------------------------
3. GAMEPLAY & ENEMY TYPES
------------------------------------------------------------------------
- DRONE BATTERY SYSTEM:
    * Drone starts with 100% Battery Health.
    * Taking a hit from an enemy target reduces Battery Health by 25%.
    * Game Over triggers when Battery reaches 0%.

- ENEMY TARGET TYPES:
    * Standard Target (Red Ring)    : Normal Speed, 1 HP, +10 pts
    * Fast Target (Magenta/Cyan)    : High Speed, Small, 1 HP, +25 pts
    * Armored Target (Crimson/Gold) : Heavy Shield, 3 HP, +50 pts

- VISUALS & AUDIO:
    * Parallax 2D Scrolling Background (Starfield, Mountains, Cyberpunk City)
    * Smoke Thruster Trails & Target Explosion Particles
    * Procedural SFX (Lasers, Explosions, Thrusters, Level-Up Chimes)
    * High Score Persistence (Saved to highscore.txt)

------------------------------------------------------------------------
